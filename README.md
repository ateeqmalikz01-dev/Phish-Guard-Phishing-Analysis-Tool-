# Phish-Guard-Phishing-Analysis-Tool-
PhishGuard (by Ateeq ur Rehman) is an offline, browser-based tool that scores emails/URLs for phishing risk. It analyzes sender headers, deep-scans links (shorteners, typosquatting, IP links), and matches 15+ scam keyword categories to output a 0–100 risk score, verdict, and "why unsafe" report. Fully offline, single HTML file, no dependencies.
